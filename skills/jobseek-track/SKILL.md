# Jobseek Track

Read [shared records](../jobseek/references/records.md) and [state commands](../jobseek/references/state-commands.md). Resolve the selected workspace and applicant before inspecting records.

1. Inspect saved jobs and applications; report the employer, role, deadline if supported, status, current material approval, last action, and next action.
2. Update status from the actual event or explicit applicant report. Preserve the source and timestamp; distinguish posting dates, retrieval times, deadlines, and submission dates.
3. Keep awaiting review, approved, filling, and awaiting applicant action distinct. Check approval before entering a filling state. Changes to the JD, dependent facts, documents, or answers can require renewed review.
4. Require an observed confirmation or explicit applicant report to mark submitted. Never infer submission from a prepared PDF, completed fields, button presence, or an interrupted browser session.
5. Detect existing applications to the same verified opening before starting duplicates. A repost or changed requisition may be distinct; investigate rather than silently combine records.
6. Preserve checkpoints and resume through the relevant skill after inspecting current state. Reconcile a modified dossier instead of overwriting it.

Record rejection, interview, offer, withdrawal, or other outcomes only when supported. Do not infer that wording caused an outcome. Tracking a deadline does not create a reminder, send a message, or schedule a search; those require a separate user request.
