# FICTIONAL SAMPLE DATA — READ FIRST

Everything in this folder is invented for testing.

Every person, employer, institution, laboratory, job posting, requisition
number, salary figure, rating, review, email address, date, event, publication,
award, and quantified result in this folder is fictional sample data created
only to exercise the job-search workflow and the Job Search Dashboard.

- The applicant, Dr. Sam Lee, is a fictional person.
- All employers named here — including NovaCell Therapeutics, North State
  University, Meridian Staffing, and QuickHire Solutions — are fictional.
- All email addresses use example.com / example.org placeholder domains and
  do not reach any real person or organisation.
- All source URLs use https://example.com/ placeholder addresses and do not
  point to real job postings.
- All employer ratings and review summaries are invented and are labelled
  as sample data wherever they appear.
- Any resemblance to any real person, employer, institution, posting, or
  event is entirely coincidental.

## Placeholder documents

The readable content sketches in `packages/` are short plain-text files.
Each states on its first line:

> PLACEHOLDER — in a real package this is a DOCX/PDF generated from the same content

Since the Option 2 port (2026-11-18), the PDF/DOCX files named in
`documents-index.json` also exist in the package folders as minimal
real-format placeholder files whose only content is a fictional-sample
header, so the kit's document index points at files that really exist
and the state helper's validation passes honestly. They are not real
application documents, and no real applicant document is included
anywhere in this dataset.

## How to use this dataset

Load it, run the workflow and dashboard acceptance checks against it, then
discard it and replace it with a real applicant's own attested data. Never
mix sample entries into a real applicant's ledger, tracker, or packages.
