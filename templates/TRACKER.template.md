# Tracker — [Applicant Name]

One row per opening. Statuses follow the pipeline: found → scored →
shortlisted → drafting → awaiting review → approved → filling → awaiting
applicant action → submitted → outcome (interview / offer / rejected /
withdrawn / closed). Record an outcome only from an actual event or the
applicant's report; where a recruiter email drives a status change for a
submitted application, link the email evidence (sender, date, subject).

## Openings

| Title | Employer | Req | Track | Status | Coverage | Unknown share | Scorecard | Deadline | Package version | Approval | Next action | Flags | Last checked |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |  |  |  |  |

Column notes:

- **Title / Employer / Req** — as on the verified official posting; Req is
  the official requisition or posting identifier.
- **Track** — Industry / Academic / Contractor / External.
- **Coverage** — the headline evidence-coverage score from
  `templates/FIT-SCORECARD.md` (unrounded value decides the threshold).
- **Unknown share** — the weighted share of Unknown competencies, reported
  alongside the coverage score.
- **Scorecard** — link or reference to the full scorecard for this opening.
- **Deadline** — closing date or best-consideration date from the official
  posting, labelled as which; a best-consideration date is priority review,
  not a hard close.
- **Package version** — current tailored package version, if any.
- **Approval** — exact-package approval status (see
  `templates/PACKAGE.template.md`); silence is not approval.
- **Flags** — eligibility, location, start-date, deadline and any other
  flags. Flags sit next to the score, never inside it.
- **Last checked** — date the official posting was last verified live.

## Screened out

Openings removed before shortlisting, with the reason kept on record.
Do not tailor for a screened-out opening.

| Title | Employer | Req | Reason screened out | Date | Source |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

Screen-out reasons include: a stated disqualifier in the official posting,
a stale or closed posting, an unnamed employer, or a duplicate of an
opening already tracked (a repost or changed requisition is investigated,
not silently merged).
